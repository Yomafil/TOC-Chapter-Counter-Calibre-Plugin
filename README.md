# TOC Chapter Counter
A plugin to count the number of chapters in an EPUB's NCX TOC and writes the result to the `#chapter_count` custom column.

# Install
1. In calibre, create a custom column with `lookup name`: `chapter_count`, `heading`:
   `Chapter Count`, and `type`: `Integer`.
2. Go in `Preferences -> Plugins -> Load plugin from file`.
3. Select the downloaded plugin release: `calibre_toc_chapter_counter.zip`.
4. Restart calibre if requested.
5. Run the "TOC Chapter Counter" action from the toolbar/menu.

# Usage
The plugin processes every EPUB in the current library that doesn't already have a `#chapter_count` value, `0` counts as having a value, it is unaffected by filtering or virtual library.

Selecting one or multiple books will force the plugin to process them, even if they already possess a `#chapter_count` value.   

The plugin only reads the NCX Table of Content

Best used with EPUBs generated by the [WebToEpub](https://github.com/dteviot/WebToEpub) browser extension.

# Build
Simply adding the following files into a zipped archived should suffice:
- `__init__.py`
- `plugin-import-name-toc_chapter_counter.txt`
- `ui.py`
- `images/icon.png`
